The Gilded Hedge — an original top-down stealth game. Wren, a young courier, must steal back her locket from a lantern-lit estate: sneak past patrolling lantern guards and their vision cones, hide in the moonbushes, pocket every silver key, then slip out the garden gate unseen. Three estates, guards that patrol, grow suspicious, investigate noises and raise the alarm, a detection meter that gives you a chance to recover, crouching, sprinting (loud!), and pebbles you can throw to pull a guard away. All art and sound are original and made in code; all sound is synthesised live with WebAudio.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. No build step, no network requests — the game is static files under game/.
